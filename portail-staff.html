TÉLÉCHARGER L'APPLICATION ANDROID
L'application Android n'est pas encore publiée sur le serveur iCHEF. Utilisez temporairement l'accès web ci-dessous. L'administrateur doit publier l'APK de diffusion signé.
  1. Touchez Télécharger l'application Android.
  2. Ouvrez le fichier APK téléchargé et confirmez son installation si Android vous le propose. Android peut demander d'autoriser cette source.
  3. Revenez à votre e-mail d'invitation et ouvrez-le de nouveau pour activer votre accès dans l'application. Si le lien ne s'ouvre pas dans l'application, utilisez « ⋮ → Ouvrir une invitation » pour coller le lien.

iPhone / iPad : iOS ne permet pas d'installer un fichier APK Android. Utilisez le portail web iCHEF Staff, puis ajoutez-le à votre écran d'accueil.

  1. Ouvrez le portail dans Safari.
  2. Touchez le bouton de partage.
  3. Choisissez Sur l'écran d'accueil, puis confirmez.
  4. Revenez à votre invitation pour activer votre accès.

Depuis un ordinateur, utilisez directement iCHEF Staff dans le navigateur. Pour installer l'application Android, ouvrez cette page sur votre téléphone Android.

Vous êtes déjà dans l'application iCHEF Staff. Aucune nouvelle installation n'est nécessaire.

OUVRIR LE PORTAIL STAFF
