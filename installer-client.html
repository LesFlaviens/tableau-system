Votre iCHEF OS, directement sur votre écran.

Retrouvez votre environnement iCHEF OS sur ordinateur, tablette ou téléphone. L'installation crée un raccourci ou une application web selon votre appareil. Elle ne donne aucun accès sans identification autorisée.

Installer iCHEF OS

Ouvrir iCHEF OS ↗

1Android · Chrome

Ouvrez cette page avec Chrome, puis choisissez Installer l'application si proposé, ou le menu ⋮ → Ajouter à l'écran d'accueil.

2iPhone · Safari

Ouvrez cette page dans Safari, touchez Partager, puis Sur l'écran d'accueil → Ajouter.

3PC · Edge ou Chrome

Ouvrez la page dans Edge/Chrome. Utilisez l'option Installer ce site comme une application dans le menu du navigateur, si disponible.

4Accès sécurisé

Après installation, connectez-vous avec votre établissement et les identifiants autorisés. Les permissions, le PIN, les sessions et les contrôles restent ceux d'iCHEF OS.

La sécurité ne change pas.

Cette page n'envoie aucun PIN, ne crée aucun compte, ne contient aucun lien d'activation personnel et n'enregistre pas les tokens. L'accès est toujours validé par le serveur iCHEF.

L'installation peut dépendre du navigateur et de la configuration HTTPS / manifeste du site. En cas d'absence de bouton, utilisez les instructions de votre appareil.
