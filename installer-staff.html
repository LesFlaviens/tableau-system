01 / Installation sécurisée

Installer iCHEF sur votre appareil

L'installation dépend de votre appareil. Sur ordinateur, n'ouvrez pas un fichier APK : l'installation se fait directement depuis le navigateur, sans téléchargement.

Détection de votre appareil…
▣PC / MacMicrosoft Edge, Chrome et navigateurs compatibles

Installation sur ordinateur

  1. Appuyez sur Installer iCHEF sur cet ordinateur.
  2. Si le navigateur ouvre le portail, choisissez « Installer l'application » dans la fenêtre Edge / Chrome ou dans le menu du navigateur.
  3. Confirmez Installer. Lancez ensuite l'application depuis le menu Démarrer, le Dock ou le bureau.
✓Aucun APK nécessaire. Le fichier APK Android n'est pas compatible avec Windows ou macOS.
Ouvrir le Portail Collaborateur ↗
◉AndroidGoogle Pixel, Samsung, Redmi, Xiaomi…

Installation recommandée avec Chrome

  1. Ouvrez le Portail Collaborateur dans Chrome.
  2. Dans le menu ⋮, choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil », selon votre navigateur.
  3. Confirmez. L'icône iCHEF apparaîtra sur votre téléphone.
  4. Ouvrez votre invitation reçue par e-mail pour activer votre compte et votre PIN si nécessaire.
Ouvrir le Portail Collaborateur ↗
Option avancée : fichier APK Android

Réservé aux téléphones Android et aux versions APK publiées et validées par votre établissement. Le fichier APK ne fonctionne pas sur PC ni iPhone. Il ne faut pas désactiver les protections de votre téléphone pour l'installer.

Télécharger l'APK Android (optionnel)
▯iPhone / iPadInstallation depuis Safari, sans APK
Ouvrir iCHEF dans Safari ↗

Installation sur iPhone ou iPad

  1. Ouvrez le portail dans Safari sur votre iPhone ou iPad.
  2. Dans le menu Partager de Safari, choisissez « Sur l'écran d'accueil ».
  3. Appuyez sur « Ajouter » puis lancez l'application depuis son icône.
  4. Revenez à votre invitation reçue par e-mail pour activer votre accès.
✓Sans téléchargement. Un APK Android ne s'installe pas sur iPhone ou iPad.

Si l'application est déjà installée, utilisez son icône. L'installation ne réinitialise pas le PIN et ne modifie pas les autorisations définies par votre établissement.

02 / Connexion

Vous avez reçu une invitation ?

Après l’installation, ouvrez iCHEF Collaborateur depuis son icône. Lors de la première connexion, suivez les instructions de l’invitation reçue de votre établissement pour activer votre accès et définir votre PIN personnel. Pour les connexions suivantes, utilisez votre identifiant et votre PIN.

Chaque accès est personnel. En cas de problème de connexion, contactez le responsable de votre établissement.
